## Why this matters

`.codex/environments/environment.toml` is a git-tracked, auto-generated file
("THIS IS AUTOGENERATED. DO NOT EDIT MANUALLY") whose setup script embeds
`VITE_SUPABASE_URL` and the Supabase **anon** JWT. The anon key is public by
design (it ships in the SPA bundle), so this is not a live credential leak —
the problem is the pattern: `.gitignore` protects `.env` / `.env.*` but not
this generated `.toml`, so a future regeneration that includes a non-public
value (service key, DB URL with password) would be committed unnoticed
through the same blind spot. Close the hole and stop tracking the file.
