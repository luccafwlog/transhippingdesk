## 5. Execução ao vivo (browser) — bloqueada neste ambiente

A política de rede do container negou todo o tráfego para `*.supabase.co`
(`403 host_not_allowed`), tanto HTTPS quanto TCP 5432; pulls de imagem Docker para um stack
local também foram bloqueados. A política é aplicada na criação do container — a liberação
feita durante a sessão não tem efeito retroativo. **A execução ao vivo deve rodar numa nova
sessão com `*.supabase.co` liberado.**

### Playbook para a nova sessão

1. `cp .env.example .env` e preencher `VITE_SUPABASE_URL`/`VITE_SUPABASE_ANON_KEY` via MCP
   Supabase (`get_project_url` / `get_publishable_keys`, projeto `fgmkhbzhaeebrsizwccx`).
2. Login interno: usuário de QA já provisionado — `qa.audit@transhipping.test`
   (perfil `admin`, full_name "QA Audit (temporario)"). Redefinir a senha via SQL:
   `update auth.users set encrypted_password = crypt('<nova-senha>', gen_salt('bf')) where email = 'qa.audit@transhipping.test';`
3. `npm install --legacy-peer-deps && npx vite` e seguir com Playwright:
   - `/viagens` → **Nova Viagem** (Armador/SCAC/Navio/IMO/Número `QA001E`/Status Ativa).
   - `/baplie` → selecionar a viagem → **Importar Baplie EDI** → `test-fixtures/qa-baplie-3cntr.edi` → conferir 3 containers staged.
   - `/manifestos` → **Importar Manifesto CNTR** → `test-fixtures/qa-manifest-cntr.xlsx` → conferir 2 B/Ls / 3 containers e a conciliação Baplie×Manifesto em `/baplie`.
   - `/veiculos` → **Importar Veiculos** → `test-fixtures/qa-veiculos.xlsx` → conferir 2 veículos no `TEMU1234567`.
   - `/containers` e `/veiculos` → paginação/scroll/overflow.
   - Taxas: Faturamento → **Validação** → selecionar os B/Ls → **Recalcular selecionados** (tabela "Salvador CNTR 2026" cobre POD BRSSA). Não há ação de cálculo em `/taxas-locais` (ver U1).
   - Emissão: Revisão → vincular cliente (auto-emite) ou B/L → Cobranças → **Pronto para faturar**; conferir linhas e impressão (window.print) no `InvoiceDetailModal`.
   - Reconciliação: gerar extrato Itaú xlsx com header `identificador` + colunas `CPF/CNPJ`, `pago em` (dd/mm/aaaa), `valor pago` (formato BR), TXID = número da invoice emitida → `/reconciliacao` → upload → **Confirmar** → verificar propagação de status (atenção a B15/B17: refresh manual pode ser necessário).
4. Limpeza: remover viagem QA, B/Ls `QABL001/QABL002`, clientes de teste, invoices e o usuário
   `qa.audit@transhipping.test` (`docs/RESET_AMBIENTE.md`).
