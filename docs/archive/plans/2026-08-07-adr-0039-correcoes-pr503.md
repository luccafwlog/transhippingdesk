# Correções da revisão do PR 503 (ADR 0039) Implementation Plan

**Goal:** Corrigir os seis achados da revisão de código do PR 503 — prazo de
conclusão do ADR — sem alterar a matemática de dias úteis, que foi validada.

**Architecture:** Cada correção vive na função compartilhada que origina o
defeito (serviço de SLA, RPC de nomes, filtro da migration), não em guardas por
call site. O congelamento do snapshot passa a exigir dados de reaberturas já
resolvidos antes de habilitar o fechamento.

**Tech Stack:** React, TanStack Query, Supabase migrations/RPC, Vitest.
