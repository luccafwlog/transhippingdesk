# Choosing a skill

Use the task and each skill's specific capability to select useful guidance.
An explicit user selection takes priority. Ordinary work with a clear approach
can proceed directly; keyword overlap alone does not justify loading a skill.

Read the selected entrypoint and only the supporting reference needed now.
Choose one of overlapping workflows instead of chaining them. Skills do not
expand the user's scope or override repository rules, tool permissions, or
existing authorization.

For harness tool-name differences, consult only its mapping:
[Codex](references/codex-tools.md), [Copilot](references/copilot-tools.md), or
[Gemini](references/gemini-tools.md). Use the tools actually available.
