# Handling review findings

Read each finding against the actual diff, callers and requirements. Distinguish
reproducible defects from preferences or speculative scenarios. Investigate
uncertain claims; explain disagreement with concrete evidence.

Implement justified fixes within scope and run affected checks. Clarify only
items whose unresolved meaning changes the implementation; independent clear
items can proceed while awaiting an answer. Respect prior business decisions
and seek a decision before materially changing them.

Report accepted findings, corrections and remaining limitations. Posting a reply
requires authorization to communicate; when authorized, reply to an inline
GitHub finding in its existing thread rather than creating an unrelated comment.
